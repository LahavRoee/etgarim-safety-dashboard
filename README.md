# דשבורד בטיחות עמותת אתגרים

> דשבורד אינטראקטיבי לניתוח אירועי בטיחות בעמותת אתגרים — לפרוץ גבולות, לדעת שאפשר.

## 🔗 גישה לדשבורד

הדשבורד זמין באופן ציבורי כאן:
**[https://lahavroee.github.io/etgarim-safety-dashboard/](https://lahavroee.github.io/etgarim-safety-dashboard/)**

## 🔒 פרטיות

זוהי **הגרסה הציבורית** של הדשבורד:
- שמות מדריכים ורכזים **אנונימיים אוטומטית** (מדריך #001, רכז #001 וכו')
- ללא תיאורי אירועים פרטניים
- ללא שמות תוכניות

הגרסה המלאה לשימוש פנימי בעמותה בלבד.

## ✨ יכולות

- **6 מסננים אינטראקטיביים** עם בחירה מרובה: נושא פעילות, גורם מממן, חומרה, שנה, גורם שורש, סטטוס
- **חיפוש בתוך כל מסנן** — ניתן לחפש בכל אחד מהמסננים
- **תובנות דינמיות** שמתעדכנות אוטומטית לפי המסננים
- **גרפים אינטראקטיביים** (Chart.js): מגמה שנתית, התפלגות חומרה, פעילויות, גורמי שורש
- **ייצוא ל-PDF** ישירות מהדפדפן

## 💻 טכנולוגיה

- HTML/CSS/JavaScript טהור
- Chart.js לגרפים
- ללא backend — הכל פועל בדפדפן
- מותאם RTL (עברית)
- נגיש WCAG AA
